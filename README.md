# Safety Management Platform

A full-stack web application for managing workplace safety incidents.

## Project Overview

The Safety Management Platform provides a digital foundation for recording, viewing and managing workplace safety incidents.

## Features

- Workplace incident management
- Incident listing
- Incident details viewing
- Flask REST API
- React user interface
- SQLite development database

## Technologies Used

- React
- JavaScript
- Python
- Flask
- SQLite
- PostgreSQL (planned for production)
- Git and GitHub

## Installation

### Backend

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r backend/requirements.txt
python backend/app.py
```

### Frontend

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

## Local Development

- Frontend: http://localhost:5173
- Backend: http://127.0.0.1:5000
